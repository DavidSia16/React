# Projeto Split-Screen App

Aplicação web desenvolvida para consolidação e aplicação prática de conceitos avançados de desenvolvimento frontend. O projeto apresenta uma interface moderna com layout split-screen responsivo em tela cheia, navegação otimizada e arquitetura limpa.

---



---

## Sobre o Projeto
Este projeto foi desenvolvido com o objetivo de colocar em prática os conceitos teóricos abordados em aula. A estrutura foi planejada para oferecer uma experiência de navegação fluida, utilizando uma interface intuitiva e adaptável a diferentes tamanhos de tela.

### Principais Funcionalidades
- **Interface Split-Screen:** Layout responsivo preenchendo 100% da viewport (editor/painel + visualização).
- **Estilização Moderna:** Construído com Tailwind CSS para garantir consistência visual e suporte a modo escuro nativo.
- **Gerenciamento de Estado Otimizado:** Atualizações de interface em tempo real sem re-renderizações desnecessárias.
- **Totalmente Responsivo:** Design adaptado para dispositivos móveis, tablets e desktops.

---

## Tecnologias Utilizadas
- **Frontend:** React.js, Vite, Tailwind CSS
- **Gerenciamento de Estado:** React Context API / Zustand
- **Roteamento:** React Router DOM
- **Padronização de Código:** ESLint, Prettier
